# Материалы карточки Google Play

Собраны 2026-08-19 для релиза 2.0.0.

- `icon-512.png` — значок приложения для магазина (512×512), из `assets/icon.png`
- `feature-graphic.png` — баннер (1024×500) с иконкой, названием и фактами
- `1-phone.png` … `6-phone.png` — скриншоты телефона в пропорции ровно 2:1
- `store-listing.md` — тексты карточки (EN/RU) и «What's new» для копирования в Play Console

⚠️ Play не принимает пропорции круче 2:1, а снимок эмулятора Pixel 9 Pro — 1280×2856 (2.23:1).
Поэтому снимки обрезаются от системных панелей и вписываются в холст высотой ×2.

Порядок экранов: главный хаб → сценарии с табами крыльев → диалог с ролями →
карточка фразы → режим «покажи экран» → крыло «Myhman geldi».
