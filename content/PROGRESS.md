## Workflow

- Даю по **5 фраз** (китайский + русский).
- Пользователь отвечает списком: `<номер>. <туркменский>` (или `?` если нужно подумать).
- Скрипт `content/update_tk.py` применяет переводы в `base.ts`.
- Git auto-commit + push после каждого apply.

## После завершения категории

Этапы по плану из `PLAN.md`:
- **Этап 1:** zh ↔ tk готов автоматически (китайский из книги + туркменский от пользователя).
- **Этап 2:** ru ↔ tk готов автоматически (русский из книги + туркменский).
- **Этап 3:** перевод русского на en/fr/es/… → пары en↔tk, fr↔tk и т.д. появляются автоматически через `translations/<язык>.ts`.
