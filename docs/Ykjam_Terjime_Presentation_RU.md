# Ykjam Terjime — Умный Разговорник

**Мобильное приложение для изучения китайского и русского языков**

---

## 1. О проекте

### Что такое Ykjam Terjime?

**Ykjam Terjime** (в переводе с туркменского — «Компактный переводчик») — это современное мобильное приложение-разговорник, которое помогает пользователям изучать китайский и русский языки и общаться на них в повседневных ситуациях.

Приложение построено на базе книги **«Русско-Китайский разговорник» (2013)** и объединяет в себе:

- ✅ Обширную базу из **2174 разговорных фраз**
- ✅ **13 тематических категорий** с ~60 подкатегориями
- ✅ **Кириллическую транскрипцию** из книги для китайских фраз
- ✅ Интуитивно понятный интерфейс
- ✅ Офлайн-режим (работает без интернета)

### Целевая аудитория

| Сегмент | Описание |
| --- | --- |
| Студенты | Изучающие китайский и русский языки |
| Бизнесмены | Предприниматели, работающие с китайскими и русскими партнёрами |
| Туристы | Путешественники в Китай и Россию |
| Диаспора | Туркмены за рубежом и их семьи |
| Экспаты | Иностранцы, живущие в Туркменистане |

### Ключевые преимущества

- 🗣️ **2174 фразы** в 13 тематических категориях (+ ~60 подкатегорий)
- 🌍 **2 языка полностью готовы**: 🇨🇳 Китайский, 🇷🇺 Русский
- 🔄 **1 язык в процессе перевода**: 🇹🇲 Туркменский
- 📖 **Кириллическая транскрипция** из книги «Русско-Китайский разговорник» (2013)
- 📴 **Офлайн-режим** — базовый функционал работает без интернета
- 🎨 **Современный дизайн** — интуитивный интерфейс по стандартам 2025 года
- 🆓 **Бесплатная модель** — 100% free, без рекламы и трекинга
- ⏸️ **Аудио произношение** — временно отключено (вернётся в будущих версиях)
- 🔜 **AI переводчик** — планируется в v2.0

### Рыночный потенциал

- Население Туркменистана: **6+ миллионов человек**
- Туркменская диаспора: **2+ миллиона человек** по всему миру
- Растущий интерес: увеличение туристического и делового потока с Китаем и Россией
- Отсутствие конкурентов: нет качественных аналогов для туркменского языка

## 2. Функциональность

### Основные модули

#### 📖 Разговорник

Сердце приложения — структурированная база из **2174 фраз**, организованных по **13 тематическим категориям** (+ ~60 подкатегорий):

| Категория | Примеры фраз |
| --- | --- |
| Приветствия | «Salam» — Привет, «Sag boluň» — Спасибо |
| Еда и рестораны | Заказ блюд, предпочтения, оплата |
| Отель | Бронирование, услуги, проблемы |
| Транспорт | Такси, автобус, направления |
| Здоровье | Симптомы, аптека, экстренная помощь |
| Покупки | Цены, торг, оплата |
| Бизнес | Деловые встречи, переговоры |
| Экстренные ситуации | Помощь, полиция, скорая |
| Числа и время | Счёт, часы, дни недели |
| Погода | Сезонные выражения, прогноз |
| Семья | Родственники, личные данные |
| Путешествия | Аэропорт, вокзал, границы |
| Общение | Общие фразы, вопросы, ответы |

Каждая фраза содержит:
- ✅ Текст на китайском/русском языке
- ✅ Перевод на туркменский
- ✅ Кириллическая транскрипция (для китайских фраз)
- ✅ Возможность добавить в избранное

#### 📝 Текстовый переводчик

Модуль свободного перевода (🔜 **Планируется в v2.0**):
- Перевод между любыми языками
- Автоматическое определение языка ввода
- История переводов
- Копирование и отправка результата

#### 🤖 ИИ-ассистент

Универсальный помощник для изучения языка (🔜 **Планируется в v2.0**):
- Объяснение грамматики
- Контекст использования фраз
- Культурные особенности
- Ответы на вопросы о языке

### Дополнительные функции

#### ⭐ Избранное
Персональная коллекция пользователя:
- Сохранение любимых фраз
- Быстрый доступ к часто используемым выражениям
- Синхронизация между сессиями

#### 🔍 Поиск
Продвинутая система поиска:
- Поиск по всем фразам и категориям
- Нечёткий поиск (fuzzy matching)
- Фильтрация по категориям
- История поисковых запросов

#### 📊 Статистика обучения
Отслеживание прогресса пользователя:
- Количество изученных фраз
- Частота использования
- Популярные категории
- Персональные рекомендации
- Дневная цель и серии дней

#### 🎲 Случайные фразы
- Быстрое изучение через случайные карточки
- Интересные факты о языках

### ⏸️ Аудио-система

**Временно отключено** (вернётся в будущих версиях):

| Язык | Технология | Статус |
| --- | --- | --- |
| Туркменский | Записи носителей (MP3) | ⏸️ Отключено |
| Китайский | Кириллическая транскрипция | ✅ Активно |
| Русский | Кириллическая транскрипция | ✅ Активно |
